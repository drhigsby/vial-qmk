# kukri

![kukri](imgur placeholder)

Kukri is a split 40% ergonomic keyboard with a 7-degree angle on each half and two optional Panasonic EVQWGD001 roller barrel encoders.

* Keyboard Maintainer: [H. Bond](https://github.com/drhigsby)
* Hardware Supported: kukri PCB
* Hardware Availability: open-source design available at maintainer's github

Make example for this keyboard (after setting up your build environment):

    make drhigsby/kukri:default

To place this keyboard into bootloader mode, press the reset button on the PCB or short the RST and GND pins on the Pro Micro.

Flashing example for this keyboard:

    make drhigsby/kukri:default:flash
